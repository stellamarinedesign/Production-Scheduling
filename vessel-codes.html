DISPLAY is what prints on the board. It is a human decision and cannot be derived — Riviera issue concept hull codes to conceal unreleased models, so SY23 is the Stella item code but 56SY is what the floor uses.

Same boat, two codes. Codes that resolve to the same Riviera model are the same vessel and display the same code, whichever product line raised the item — a lifter and a helm seat box for one boat must not print different codes. Grouped rows are marked ALIAS and edit together. Grouping is on the Riviera model, never the hull prefix: 56 and SY26 share hull 5000 but are different boats.
