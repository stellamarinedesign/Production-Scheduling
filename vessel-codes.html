The display code is the boat. It is what the floor reads and what the board prints, so it is the key here rather than something derived further down the line. Every ERP code that resolves to it sits on the same row — SY20 and 43SY are one boat, not two.

A boat usually builds more than one product. One line per boat tags each with the line it is best known by, lifters first. Split by product gives it a row per category, so the 56SY lifter and the 56SY boarding ladder are separate.

Grouping is manual, and has to be. Riviera call one hull both 56SY and 5000SY, and 56 was office shorthand. Nothing upstream records which codes mean the same boat, so Rename sets what a line reads and Split moves a code off a row that grouped wrongly.
